# OmniM 前端画像与旅程

> **文档定位。** 本文把 [VISION_SCOPE](VISION_SCOPE.zh-CN.md) 中的定位转化为具体用户旅程。每一步都标出用户期望的反馈，每个期望都映射到 [PRD_FRONTEND](PRD_FRONTEND.zh-CN.md) 中的需求 ID。
>
> **双轨维护义务**：`PERSONAS_JOURNEYS.zh-CN.md` 是持续维护的译文。保持章节编号与需求 ID 在同一次变更中对齐。
>
> **诚实规则。** 旅程描述的是**目标**体验；当前实现与目标的差异记录在 [CODE_DEVIATIONS §7](../status/CODE_DEVIATIONS.zh-CN.md)。

## 1. 画像

### 1.1 P1 — 专业建模工程师

| 属性 | 内容 |
|---|---|
| 工作情境 | 桌面工作站，同一时间一个项目，长时间会话 |
| 技能 | 懂专业；对软件有一定容忍度，但对数据丢失零容忍 |
| 主要任务 | 创建墙/板/设备、放置目录构件、调整属性、保存 |
| 当前痛点 | 创建入口埋在工具栏弹层里；对象名是时间戳；没有显式保存按钮 |
| 成功信号 | "我信得过这个文件，关掉还能回来。" |

### 1.2 P2 — 专业负责人 / 审阅者

| 属性 | 内容 |
|---|---|
| 工作情境 | 打开同事的模型，以阅读为主，很少编辑 |
| 技能 | 专业水平高，对在面板里翻找的耐心低 |
| 主要任务 | 选择与查看、读属性集、测距离/面积、剖切、核对楼层 |
| 当前痛点 | 属性面板以居中浮层出现；测量结果是临时的 |
| 成功信号 | "不用开控制台，一分钟内能回答一个模型问题。" |

### 1.3 P3 — 目录与标准管理员

| 属性 | 内容 |
|---|---|
| 工作情境 | 维护构件定义、系列决策树、单位与语言包 |
| 技能 | 标准知识深，习惯表单与表格 |
| 主要任务 | 编辑 `ComponentDef` 参数与连接点、编辑系列树、导入导出 `.omnimlib`/`.omnimseries` |
| 当前痛点 | 管理页与工作区视觉上不是一套；没有校验汇总 |
| 成功信号 | "错的定义在进入模型之前就被拦住。" |

## 2. 旅程 J1 — 首次启动到首个已保存模型

| 步骤 | 用户动作 | 期望反馈 | 需求 |
|---|---|---|---|
| J1.1 | 启动应用 | 看到项目首页，而不是一个不明来源的预载模型 | UI-DAT-01 |
| J1.2 | 选择**新建项目**或示例 | 询问名称、单位制与位置；显示模板预览 | UI-DAT-01, UI-DAT-07 |
| J1.3 | 进入工作区 | 外壳加载完成，视口显示空状态引导 | UI-SHL-02, UI-FBK-09 |
| J1.4 | 在功能区点**墙体** | 功能区显示当前工具，左侧面板显示墙体参数 | UI-SHL-07 |
| J1.5 | 拾取两点 | 预览跟随光标，捕捉指示可见 | UI-INT-02 |
| J1.6 | 按回车 | 对象创建并命名（`Wall-001`），自动选中 | UI-INT-09 |
| J1.7 | 按 Ctrl+S | 状态栏显示保存中，随后显示"已保存 HH:MM:SS"，脏标记消失 | UI-DAT-02, UI-DAT-03, UI-SHL-08 |
| J1.8 | 重开文件 | 对象数量与几何完全一致 | UI-DAT-02 |

**失败路径：** 保存失败 → 保持脏状态并给出重试动作（UI-DAT-02）；创建被拒 → 面板内显示原因，而不是浏览器弹窗（UI-FBK-04）。

## 3. 旅程 J2 — 目录构件放置

| 步骤 | 用户动作 | 期望反馈 | 需求 |
|---|---|---|---|
| J2.1 | 打开构件库 | 右侧停靠里的标签页，而不是弹窗接管 | UI-SHL-02 |
| J2.2 | 按专业与系列筛选 | 数量与空状态立即更新 | UI-FBK-01 |
| J2.3 | 回答系列选择器问题 | 合法构件收窄；非法选项禁用并说明原因 | UI-FBK-04 |
| J2.4 | 调整参数 | 数值框显示单位与取值边界 | UI-INT-10 |
| J2.5 | 在视口放置 | 幽灵预览使用真实目录网格 | UI-INT-02 |
| J2.6 | 确认 | 对象出现并带 `catalog_ref`；属性显示系列来源 | UI-SHL-03 |

## 4. 旅程 J3 — 中断、失败与恢复

| 步骤 | 用户动作 | 期望反馈 | 需求 |
|---|---|---|---|
| J3.1 | 导入大体积 IFC | 显示进度且可取消；界面不卡死 | UI-FBK-03 |
| J3.2 | 导入中途失败 | 明确的错误码、原因与恢复动作；不留静默的半成品状态 | UI-FBK-04, UI-FBK-10 |
| J3.3 | 浏览器或服务崩溃 | 重启后提示恢复最近自动保存 | UI-DAT-05 |
| J3.4 | 用户放弃恢复 | 丢弃前必须显式确认 | UI-INT-07, UI-DAT-06 |
| J3.5 | 外部程序修改了项目文件 | 界面切为只读并解释冲突 | UI-DAT-08 |
| J3.6 | 用户删除父对象 | 删除前列出受影响的子对象 | UI-INT-07, UI-DAT-10 |

## 5. 旅程 J4 — 审阅、测量与剖切

| 步骤 | 用户动作 | 期望反馈 | 需求 |
|---|---|---|---|
| J4.1 | 选中对象 | 右侧停靠立即显示属性，视口高亮 | UI-SHL-03 |
| J4.2 | 切换到楼层视图 | 只显示所选楼层，控件显示当前楼层 | —（缺口，见 Q4） |
| J4.3 | 启用剖切 | 剖切面手柄可拖动，裁切即时生效 | —（缺口，见 Q4） |
| J4.4 | 测量距离 | 测量结果持久化到项目并可列出 | —（缺口，见 Q4） |
| J4.5 | 查看被禁用的参数 | 悬停提示解释禁用原因 | UI-FBK-04 |

## 6. 旅程 J5 — 重开与移交

| 步骤 | 用户动作 | 期望反馈 | 需求 |
|---|---|---|---|
| J5.1 | 打开项目首页 | 最近文件显示路径、时间与大小 | UI-DAT-01 |
| J5.2 | 打开他人创建的文件 | 缺失的目录/系列依赖被明确列出 | UI-DAT-09 |
| J5.3 | 处理上次会话的未保存内容 | 恢复或丢弃的选择必须显式 | UI-DAT-05 |
| J5.4 | 导出用于交换 | 对话框说明所选格式的已知限制 | UI-FBK-04 |
| J5.5 | 移交 | 项目元信息与单位制可见且正确 | UI-DAT-07 |
