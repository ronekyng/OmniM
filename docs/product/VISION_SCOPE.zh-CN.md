# OmniM 前端愿景与范围

> **文档定位。** 本文是前端文档体系的产品层，回答*为什么*要有这个界面、服务*谁*、以及*什么算完成*。实现细节不在这里，见 `docs/specification/ui/`。
>
> **双轨维护义务**：`VISION_SCOPE.zh-CN.md` 是英文版的持续维护译文。修改英文版时，必须在同一次变更中同步更新中文版：保持章节编号、表格与需求 ID 一致。
>
> **诚实规则。** 本文中的内容都是**目标**，不是对现状的声明。现状见 [WEB_ARCHITECTURE](../architecture/WEB_ARCHITECTURE.md)，评分见 [FRONTEND_MATURITY](../status/FRONTEND_MATURITY.md)。

## 1. 目的

OmniM 的建模内核已经足够深：类型化命令、撤销/重做、特征引擎、BRep 内核、目录/系列体系、IFC 导入导出，以及 AI 翻译层。差距在**前端的产化**：界面能执行操作，但还不像商业工程软件那样工作。

本文固定目标：对 OmniM 前端而言"商用级"意味着什么、要服务哪些用户、哪些结果是可测量的。

## 2. 产品定位

> **OmniM 是一款本地优先、多专业协同的工程建模器，面向小型团队：在一个应用内建模、标准化并交换建筑、土木、工厂与机械数据，命令可复核，格式边界诚实。**

定位约束：

- **本地优先。** 单个本地服务 + 浏览器客户端，不依赖云，不强制账号。
- **多专业。** 建筑、土木、工厂、机械共用一套数据模型；界面不得假装只有建筑。
- **命令可复核。** 每次变更都是一条 Omcom 命令，可撤销、可查看。
- **边界诚实。** 不支持的能力要明说，而不是藏起来。

## 3. 目标用户

| 画像 | 主要目标 | 使用频率 | 参考 |
|---|---|---|---|
| **P1 专业建模工程师** | 把意图变成几何并安全保存 | 每日 | [PERSONAS_JOURNEYS §1.1](PERSONAS_JOURNEYS.zh-CN.md) |
| **P2 专业负责人 / 审阅者** | 查看、测量、剖切并校验他人模型 | 每周 | [PERSONAS_JOURNEYS §1.2](PERSONAS_JOURNEYS.zh-CN.md) |
| **P3 目录与标准管理员** | 维护构件定义、系列树、单位与语言包 | 每月 | [PERSONAS_JOURNEYS §1.3](PERSONAS_JOURNEYS.zh-CN.md) |

本轮**明确不服务**：消费者、纯移动端用户、多租户云端协作者。

## 4. 范围内工作流

| ID | 工作流 | 画像 | 成功条件 |
|---|---|---|---|
| W1 | 首次启动 → 新建项目 → 创建 → 保存 → 重开 | P1 | 模型跨重启存活，零数据丢失 |
| W2 | 通过系列决策树放置目录构件 | P1 | 实例化正确的 `ComponentDef`，参数合法 |
| W3 | 审阅模型：选择、读属性、测量、剖切 | P2 | 不用控制台就能回答"这是什么、多大" |
| W4 | 从中断或失败操作中恢复 | P1 | 无静默数据丢失，每个失败都有恢复动作 |
| W5 | 维护目录/系列并切换语言与单位 | P3 | 定义可编辑，界面完全本地化 |

## 5. 明确的非目标

1. **照片级渲染。** 视觉目标是"可读的工程视口"，不是宣传图。
2. **云端协作与多租户账号。** 单用户本地服务是当前交付形态。
3. **移动端与触屏优先界面。** 只做桌面级指针 + 键盘工作流。
4. **设计工具对齐。** 外壳不是 Figma 式自由画布，而是停靠式工程工作区。
5. **完整 WCAG AAA。** 目标是关键路径 WCAG 2.2 AA，高对比主题作为辅助。
6. **插件 UI 市场。** 面板注册表是内部扩展点，不是公开插件 SDK。

这些非目标是约束性的：违反它们的提案需要走 RFC。

## 6. 成功指标

产品级结果，按发布门禁测量。详细预算见 [PERFORMANCE](../specification/ui/PERFORMANCE.zh-CN.md)。

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 新用户到首个已保存模型 | ≤ 10 分钟（示例项目） | 主持式任务测试 |
| 保存/重开数据丢失 | 0 个对象 | 自动化往返 e2e |
| 崩溃到恢复的数据损失 | ≤ 5 分钟工作量 | 恢复演练 |
| 首次有意义绘制（参考机） | ≤ 2.5 s P95 | 性能夹具 |
| 关键路径 WCAG 2.2 AA 符合度 | 100% | axe + 人工键盘走查 |
| 用户可见字符串外置率 | 100% | 字符串扫描 |
| 支持浏览器矩阵通过率 | 100% | 兼容性套件 |
