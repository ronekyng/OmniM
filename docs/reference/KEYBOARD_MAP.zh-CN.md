# OmniM 快捷键表

> **文档定位。** 面向用户的快捷键参考。**命令注册表是真值**（[INTERACTION](../specification/ui/INTERACTION.zh-CN.md) §5）；本文镜像它，注册表落地后由 `scripts/gen_keymap.py --check` 校验。
>
> **双轨维护义务**：`KEYBOARD_MAP.zh-CN.md` 是持续维护的译文。按键、命令与作用域必须逐行一致。
>
> **诚实规则。** 标记 ✅ 的绑定今天已存在于代码；📅 是契约要求、尚未实现。

## 1. 真值来源

| 层 | 产物 |
|---|---|
| 命令定义 | `web/src/app/App.tsx` 的 `commands` 注册表 |
| 快捷键绑定 | 注册表行的 `shortcut` 字段 + `App.tsx` 全局分发 |
| 本文 | 镜像注册表；`gen_keymap.py --check` 校验双语一致 |
| 冲突解决 | 注册表加载时，同作用域重复绑定直接让构建失败 |

## 4. 拾取会话

| 快捷键 | 动作 | 状态 |
|---|---|---|
| `Enter` | 完成拾取 | ✅ |
| `Backspace` | 移除最后一个点 | ✅ |
| `Esc` | 取消会话 | ✅ |
| `Shift`（按住） | 正交约束 | 📅 |

**目标规则：** 拾取过程中 `Delete` 应被忽略；`Backspace` 永远表示"撤销一个点"。**当前未强制：** `App.tsx` 只特判了 `Backspace`，按 `Delete` 仍会删除选中对象（见 [CODE_DEVIATIONS §7](../status/CODE_DEVIATIONS.zh-CN.md) 第 7.11 行）。

## 7. 冲突规则

| 情况 | 解决方式 |
|---|---|
| 同一按键出现在两个作用域 | 更窄的作用域优先（弹窗 > 树 > 视口 > 全局） |
| 同一作用域内重复 | 注册失败，构建失败 |
| 文本框聚焦 | 全局快捷键禁用，除非 `allowInInput` |
| `Esc` | 永远解决最内层可取消动作 |
| 操作系统保留组合 | 不绑定；在文档中标注不可用 |

## 8. 变更流程

1. 在注册表中新增或修改绑定。
2. 重新生成本文档（`gen_keymap.py`）。
3. 若绑定对用户可见，在 CHANGELOG 增加一行。
4. 若改变肌肉记忆，在发布说明中注明。

## 9. 非目标

1. 本版本的用户自定义快捷键。
2. 按专业的绑定集合。
3. 手柄或 3D 鼠标绑定。
