# OmniM 前端成熟度

> **文档定位。** 本文是前端成熟度的真值层。它按 ISO/IEC 25010 对现状评分，并跟踪需求覆盖率。目标与契约在 `docs/product/` 与 `docs/specification/ui/`。
>
> **双轨维护义务**：`FRONTEND_MATURITY.zh-CN.md` 是持续维护的译文。评分、计数与需求 ID 在两份文件中必须一致。
>
> **评分规则。** 评分描述今天存在的代码，而不是计划。3 分要求能力已实现且有验证物。

## 1. 目的与方法

商用就绪度不是一个数字。ISO/IEC 25010 给出九个质量特性；每个按 1–5 评分，并附证据与必须达到目标的门禁。

| 分数 | 含义 |
|---|---|
| 1 | 缺失——没有实现，也没有策略 |
| 2 | 原型——演示可用，正常使用会出问题 |
| 3 | 可用——主流程可用，已知缺口有记录 |
| 4 | 商用——可测量、有门禁、可支持 |
| 5 | 业界最佳——有基准并持续改进 |

总分是算术平均，保留一位小数。它**不是**意图的平均值。

**解读：** 前端是一个功能原型，几何/视口内核强，产品外壳弱。最低分正好集中在"像 demo"的来源：可靠性、安全性、支持性、兼容性。
