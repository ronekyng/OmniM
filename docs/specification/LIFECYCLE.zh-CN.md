# OmniM 项目全生命周期数据模型

## 1. 概述

OmniM 将工程项目全生命周期作为数据模型的一等公民来支持。生命周期数据并非外部的项目管理元数据,而是与几何、对象和关系一同建模,使每个工程对象都携带从规划到退役拆除的完整历史记录。

生命周期组织为九个阶段。不同项目类型(建筑、土木、工厂、机械)可能跳过某些阶段——例如,建筑项目通常跳过 `PRODUCTION`(生产),而工厂项目则在移交后进入该阶段。

```
Planning → Design → Procurement → Construction → Commissioning & Acceptance
    → Asset → Operation & Maintenance → Production → Decommissioning
```

### 阶段汇总

| 序号 | 阶段 | 中文 | 目的 |
|------|------|------|------|
| 1 | Planning | 规划 | 项目立项、可行性研究、选址、需求 |
| 2 | Design | 设计 | 建筑、结构、机电、土木、工厂、机械设计 |
| 3 | Procurement | 采购 | 招投标、合同、材料与设备采购、供应链 |
| 4 | Construction | 施工 | 建造、安装、进度、质量、安全、竣工实测 |
| 5 | Commissioning & Acceptance | 调试验收 | 测试、检验、试运行、验收、移交 |
| 6 | Asset | 资产 | 资产登记、质保设置、向业主移交 |
| 7 | Operation & Maintenance | 运维 | 运行、维护、设施管理、能源 |
| 8 | Production | 生产 | 工业生产运行(仅工厂/制造业) |
| 9 | Decommissioning | 退役拆除 | 报废、拆除、处置、场地恢复 |

---

## 2. 阶段详情

### 2.1 规划 (Planning)

**目的**:项目立项与可行性确定。

**关键数据**:
- 项目任务书与需求
- 选址与土地利用
- 地形与现状测量
- 分区、环境及法规约束
- 可行性研究(技术、经济、环境)
- 预算上限与进度框架

**关联对象**:场地、地形模型、既有公用设施、线型走廊。

---

### 2.2 设计 (Design)

**目的**:将需求转化为可建造的模型、图纸和规格说明。

**子专业**:
- **建筑**:外壳、空间布局、洞口、饰面
- **结构**:主体结构、基础、钢筋、连接
- **机电 (MEP)**:暖通、给排水、电气、消防分配
- **土木**:道路、土方、排水、场地公用设施
- **工厂**:设备布置、管道、仪表、结构钢
- **机械**:零件、装配件、几何尺寸与公差 (GD&T)、产品制造信息 (PMI)、产品结构

**关键数据**:3D 模型、2D 图纸、计算书、规格说明、设计变更、碰撞报告。

**关联对象**:所有设计元素(墙、梁、管道、设备、零件等)。

---

### 2.3 采购 (Procurement)

**目的**:采购材料、设备和服务;管理合同与交付。

**关键数据**:
- 物料清单 / 工程量计算
- 招标包与评标
- 合同与采购订单
- 供应商与厂商数据
- 交付计划与跟踪
- 成本估算与实际成本

**关联对象**:已采购元素(阀门、泵、钢构件、材料、零件)。

---

### 2.4 施工 (Construction)

**目的**:建造并安装设计工程。

**关键数据**:
- 施工进度计划(WBS、活动、依赖关系)
- 进度更新(按对象完成百分比)
- 质量检验与不合格报告
- 安全事件与隐患
- RFI、提交资料、变更单
- 竣工实测条件与偏差

**模型集成**:
- 每个对象关联其施工活动
- 4D 模拟(时间 + 3D)
- 以颜色编码可视化进度
- 缺陷与问题定位到模型几何上

---

### 2.5 调试验收 (Commissioning & Acceptance)

**目的**:验证已安装工程符合设计意图与法规要求;向业主移交。

**关键数据**:
- 设备与系统调试记录
- 测试报告(压力、电气、功能、性能)
- 试运行日志
- 检验与验收证书
- 消缺清单与缺陷处置
- 竣工模型与已安装条件的验证
- 移交资料包(运维手册、质保、证书)

**关联对象**:设备、系统、已完成元素、竣工对象。

---

### 2.6 资产 (Asset)

**目的**:将移交对象登记为带有完整生命周期属性的可管理资产。

**关键数据**:
- 资产登记(资产 ID、条码/二维码、分类)
- 制造商、型号、序列号
- 安装日期与调试日期
- 质保条款与到期日
- 预期使用寿命与更换计划
- 折旧与财务数据
- 备件库存
- 资产层级(系统 → 组件 → 子组件)

**关联对象**:所有移交的、成为可管理资产的物理元素。

---

### 2.7 运维 (Operation & Maintenance)

**目的**:运营设施并维护资产处于良好工作状态。

**关键数据**:
- **运行**:运行参数、设定值、日志、班次
- **维护**:工单(预防性、纠正性、预测性)、维护日志、停机记录
- **设施管理**:空间利用、占用、租赁
- **能源**:消耗、账单、能效跟踪
- **问题**:故障、报警、服务请求

**模型集成**:
- 在 3D 模型中定位资产以进行维护
- 从模型中访问手册、规格与历史记录
- 实时传感器数据叠加(接入数字孪生能力)

---

### 2.8 生产 (Production)

**目的**:对于工业/工厂项目,运行生产工艺以制造产品。建筑与土木项目通常跳过此阶段。

**关键数据**:
- 生产计划与排程
- 生产批次、批号与产量记录
- 原材料与耗材消耗
- 产品质量与良率数据
- 设备停机与 OEE(设备综合效率)
- 生产日志与班次报告

**关联对象**:生产线、反应器、容器、储罐、泵、制造设备。

**注**:对于工厂项目,生产与运维通常并行运行——设备必须在生产持续的同时得到维护。单个资产可能同时拥有维护记录(运维阶段)和生产记录(生产阶段)。

---

### 2.9 退役拆除 (Decommissioning)

**目的**:在寿命终期安全地报废、拆除、拆毁和处置资产;恢复场地。

**关键数据**:
- 退役拆除计划与程序
- 危险物质调查(石棉、化学品、辐射)
- 拆除顺序与排程
- 拆毁记录与进度
- 废物处置与回收日志
- 资产处置 / 残值回收记录
- 场地恢复与修复
- 最终竣工结项文档

**关联对象**:退役资产、计划拆除的结构、受污染区域。

---

## 3. 跨阶段数据连续性

### 3.1 跨阶段对象身份
每个工程对象在整个生命周期中保持其身份。其状态通过阶段转换演进:

```
Designed → Procured → Installed → Commissioned → Registered as Asset
    → Maintained → (Producing) → Decommissioned
```

### 3.2 阶段转换
| 转换 | 关键交接数据 |
|------|--------------|
| 规划 → 设计 | 需求、场地约束、可行性 |
| 设计 → 采购 | 工程量计算、规格说明、材料表 |
| 采购 → 施工 | 交付状态、供应商数据、采购订单 |
| 施工 → 调试验收 | 竣工实测条件、安装记录、测试就绪状态 |
| 调试验收 → 资产 | 验收证书、质保、运维手册 |
| 资产 → 运维 | 资产登记、维护计划、运行规程 |
| 资产/运维 → 生产 | 产能、工艺参数、设备就绪状态 |
| 运维/生产 → 退役拆除 | 服役历史、剩余寿命、危险物质数据 |

## 4. 对象上的生命周期元数据

每个工程对象都可携带生命周期元数据:

```json
{
  "lifecycle": {
    "current_phase": "OPERATION_MAINTENANCE",
```

## 5. 项目类型阶段路径

不同项目类型遵循不同的阶段路径:

| 项目类型 | 典型路径 |
|----------|----------|
| **建筑** | 规划 → 设计 → 采购 → 施工 → 调试验收 → 资产 → 运维 → 退役拆除 |
| **土木(道路、桥梁)** | 规划 → 设计 → 采购 → 施工 → 调试验收 → 资产 → 运维 → 退役拆除 |
| **工厂(工艺、电力)** | 规划 → 设计 → 采购 → 施工 → 调试验收 → 资产 → 运维 + 生产 → 退役拆除 |
| **机械(产品)** | 规划 → 设计 → 采购 → 施工(制造)→ 调试验收 → 资产 → 运维 → 生产 → 退役拆除 |

## 6. 数据保留策略

| 数据类型 | 保留期限 | 备注 |
|----------|----------|------|
| 规划与可行性 | 设施寿命 + 10 年 | 法定归档 |
| 设计模型与图纸 | 设施寿命 + 10 年 | 法定归档 |
| 采购合同 | 设施寿命 + 10 年 | 法定归档 |
| 施工记录 | 设施寿命 + 10 年 | 法定归档 |
| 调试验收记录 | 设施寿命 + 10 年 | 法定归档 |
| 资产登记 | 直至退役 + 10 年 | 财务要求 |
| 维护日志 | 设备寿命 | 随设备更换 |
| 生产记录 | 按行业法规(通常 5-10 年) | 法规合规 |
| 传感器 / IoT 数据 | 原始数据 3 年,汇总数据永久 | 合规要求各异 |
| 退役拆除记录 | 永久 | 环境责任 |
