# OmniM 界面国际化与本地化

> **契约范围。** 本文固定字符串外置、语言选择、ICU 格式、数字/日期/单位处理、伪本地化、键名卫生、RTL 就绪与翻译流程。它是需求 `UI-I18N-01` … `UI-I18N-07` 的规范来源。
>
> **双轨维护义务**：`I18N_L10N.zh-CN.md` 是持续维护的译文。在同一次变更中保持章节编号、键名示例与需求 ID 一致。
>
> **状态。** §3/§4/§5 内核已交付（2026-11-03，Phase 8-5 批次）：`web/src/shared/i18n.ts`（`t()`/`tPlural()`/`useI18n()` + `Intl.PluralRules` 与数字/日期/单位格式函数）、`web/src/shared/i18n/{zh-CN,en-US}.ts` 双词典、持久化 `omnim.locale` 与 `<html lang>` 同步、`e2e/language.spec.ts`。§2 字符串外置（UI-I18N-01）仍在进行：TitleBar/离开确认首批外置，其余高频面（状态栏、面板、创建表单）未迁。

## 1. 目的与范围

OmniM 面向中文与英文工程团队交付。因此本地化是产品能力，不是事后翻译。

范围内：浏览器客户端的界面字符串、数字/日期/单位呈现、语言切换、语言环境感知的校验消息。

范围外：模型数据、文件格式、IFC 实体名、服务端日志。

## 2. 字符串外置

| 规则 | 取值 |
|---|---|
| 覆盖 | 100% 用户可见字符串，包括 `aria-label`、`title`、占位符、提示、错误与空状态文本 |
| 真值 | `web/src/shared/i18n/<locale>.ts`，每种语言一个词典 |
| 访问 | `useI18n()` hook 或 `t('key')`；禁止字符串拼接 |
| 禁止 | `.tsx` 中除词典外的中英文面量 |
| 动态文本 | ICU 占位符；绝不做字符串运算 |
| 服务端字符串 | 通过错误码映射，不直接展示原文 |
| 需求 | UI-I18N-01 |

强制：`scripts/check_ui_contracts.py --strings` 扫描 `i18n/` 之外的 `.tsx`/`.ts` 中的 CJK 字面量；`--strict --strings` 让构建失败。**已知限制：** 扫描只识别 CJK，硬编码英文 JSX 文本尚未检出（📅 `UI-I18N-01`）。

## 3. 语言选择与回退

| 规则 | 取值 |
|---|---|
| 支持语言 | `zh-CN`（默认）、`en-US` |
| 检测顺序 | 已存用户选择 → `navigator.languages` 交集 → `zh-CN` |
| 回退 | 缺失键回退到 `en-US`，仅开发环境直接渲染键名 |
| 切换 | 立即生效，不重载；存入 `localStorage`（`omnim.locale`） |
| 文档属性 | 切换时更新 `<html lang>` |
| 格式 | 切换同时重渲染数字、日期与单位 |
| 需求 | UI-I18N-02 |

**规则：** 生产环境缺失键渲染 `en-US` 值并记录诊断事件；绝不显示 `undefined` 或原始键名。

## 4. 消息格式化（ICU）

| 需求 | 模式 |
|---|---|
| 复数 | `{count, plural, =0 {No objects} one {# object} other {# objects}}` |
| 选择 | `{type, select, wall {Wall} slab {Slab} other {Object}}` |
| 数字 | `{value, number, ::precision-increment/0.001}` |
| 日期/时间 | `{ts, date, ::yyyyMMdd}` 与 `{ts, time, ::HHmmss}` |
| 单位 | `{value, number} {unit}`，单位名来自词典 |

规则：

1. 禁止手写复数（界面代码中 `count === 1 ? … : …` 属违规）。
2. 中文没有复数范畴，但词典仍必须声明 `other`，以便安全加入英文。
3. 消息键扁平、点分；嵌套不超过两层。

需求：UI-I18N-03。

## 5. 数字、日期、单位

| 上下文 | 格式来源 | 示例（zh-CN / en-US） |
|---|---|---|
| 坐标 | `Intl.NumberFormat`，3 位小数 | `1.234` / `1.234` |
| 大数字 | 按语言分组 | `1,000` / `1,000` |
| 日期 | `Intl.DateTimeFormat`，短格式 | `2026/10/29` / `10/29/2026` |
| 时间 | `zh-CN` 24 小时制，`en-US` 按语言默认 | `14:05:09` / `2:05:09 PM` |
| 单位 | 显示单位制设置 | `m` / `m`、`mm` / `mm` |
| 角度 | 度符号，1 位小数 | `45.0°` |

规则：

1. 小数分隔符跟随语言环境；存储值永不改变。
2. 单位切换是显示设置；不得静默重缩放已存几何。
3. 单位有歧义时（目录 mm 与视口 m），始终显示单位。

需求：UI-I18N-04。

## 6. 伪本地化

伪语言（`en-XA`）把 ASCII 扩长约 40%，加注音字符与括号。

| 检查 | 通过条件 |
|---|---|
| 截断 | 标签、按钮、标签页无被裁剪 |
| 溢出 | 长词换行或省略并提供提示 |
| 布局 | 1280×720 与 1440×900 下无重叠 |
| 拼接 | 不存在由片段拼接的句子（表现为语序错乱） |
| 需求 | UI-I18N-05 |

伪本地化在 G2 纳入视觉回归套件。

## 7. 键名规范与卫生

```text
<area>.<component>.<element>
  area:      common | shell | tree | props | create | catalog | series | lib | sketch | console | ai | error | a11y
  component: 面板或功能名
  element:   label | title | hint | placeholder | action | empty | error
```

示例：`shell.menu.file.save`、`props.field.length.label`、`error.save.failed.title`。

| 检查 | 规则 |
|---|---|
| 未使用键 | 每个版本报告；一个次要版本后移除 |
| 缺失键 | 引用不存在的键时构建失败 |
| 重复值 | 仅当语义不同才允许 |
| 跨域复用键 | 禁止；键要描述上下文 |
| 需求 | UI-I18N-06 |

## 8. RTL 就绪

本轮不交付 RTL，但布局不得阻碍后续支持。

| 规则 | 取值 |
|---|---|
| CSS | 只用逻辑属性（`margin-inline-start`，不用 `margin-left`） |
| 图标 | 方向性图标通过 `data-dir` 钩子镜像 |
| 数字 | RTL 文本中的数字保持 LTR |
| 视口 | 相机控制不变；只有外壳镜像 |
| 需求 | UI-I18N-07 |

强制：样式扫描标记新代码中的物理方向属性；历史例外需列出到期日。

## 9. 翻译流程

| 步骤 | 责任人 | 产出 |
|---|---|---|
| 1. 编写英文源 | 前端 | 键与 `en-US` 值合入 |
| 2. 提取 | 脚本 | `i18n/zh-CN.ts` 差异与未翻译键 |
| 3. 翻译 | 译者 / 领域专家 | 更新 `zh-CN` 值 |
| 4. 上下文评审 | 产品 / 专业负责人 | 变更界面的截图评审 |
| 5. 校验 | CI | 键对齐、伪语言、截图差异 |
| 6. 发布说明 | 前端 | CHANGELOG 中的语言覆盖 |

规则：翻译记忆库可选；专业术语必须遵循 [GLOSSARY](../../reference/GLOSSARY.zh-CN.md)；新术语先入术语表再翻译。

## 10. 非目标

1. 本版本除 `zh-CN` 与 `en-US` 之外的更多语言。
2. 运行时机器翻译。
3. 本地化模型内容或文件名。
4. 交付 RTL。
