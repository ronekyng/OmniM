# OmniM 界面外壳与信息架构

> **契约范围。** 本文固定应用外壳：层级、区域、停靠、持久化、状态栏、响应式折叠与命令面板。它是需求 `UI-SHL-01` … `UI-SHL-12` 的规范来源。
>
> **双轨维护义务**：`IA_SHELL.zh-CN.md` 是持续维护的译文。在同一次变更中保持章节编号、表格与需求 ID 一致。
>
> **状态。** 设计契约。现状见 [WEB_ARCHITECTURE](../../architecture/WEB_ARCHITECTURE.zh-CN.md)，差距见 [FRONTEND_MATURITY](../../status/FRONTEND_MATURITY.zh-CN.md)。

## 1. 目的与范围

外壳是产品的第一印象，也是长期操作框架。它必须像停靠式工程工作区：区域稳定、缩放可预期、布局可持久化，且不用弹层接管视口。

不在范围：视觉语言（见 [DESIGN_SYSTEM](DESIGN_SYSTEM.zh-CN.md)）、命令语义（见 [INTERACTION](INTERACTION.zh-CN.md)）、项目生命周期（见 [DATA_INTEGRITY](DATA_INTEGRITY.zh-CN.md)）。

## 2. 应用层级

### 2.1 项目层

入口界面。列出最近项目，提供新建、打开、示例。没有视口，也没有建模命令。

| 规则 | 取值 |
|---|---|
| 路由 | `/projects` |
| 默认落地 | 是，当没有打开的项目时 |
| 退出 | 打开或新建项目后进入工作区 |
| 需求 | UI-SHL-01, UI-DAT-01 |

### 2.2 工作区层

主建模界面。拥有七个区域、视口与项目会话。

| 规则 | 取值 |
|---|---|
| 路由 | `/`（工作区根） |
| 标题 | 项目名 + 脏标记 |
| 面包屑 | `项目 / 专业 / 当前工具` |
| 需求 | UI-SHL-01, UI-SHL-10 |

### 2.3 编辑器层

专注的创作界面，临时替换工作区视口，但保持外壳风格一致。

| 编辑器 | 路由 | 外壳 |
|---|---|---|
| 构件编辑器 | `/component-editor` | 菜单栏 + 编辑器工具栏 + 特征面板 + 2D/3D 画布 |
| 图库管理器 | `/library-manager` | 菜单栏 + 树 + 表单 + 预览 |
| 系列管理器 | `/series-manager` | 菜单栏 + 决策树 + 详情表单 |
| 需求 | UI-SHL-01, UI-SHL-10 |

**规则：** 每个编辑器都通过面包屑返回工作区；`Esc` **不用于**导航（它先取消当前工具）。

## 3. 工作区区域

### 3.1 七个区域

```text
┌──────────────────────────────────────────────────────────────┐
│ 1 菜单栏（32 px）                                             │
├──────────────────────────────────────────────────────────────┤
│ 2 功能区（72 px，可折叠）                                     │
├────────────┬────────────────────────────────┬────────────────┤
│ 3 左停靠   │ 4 视口                         │ 5 右停靠       │
│            │                                │                │
│ 240–400 px │  弹性，最小 480 px             │ 260–600 px     │
│            ├────────────────────────────────┤                │
│            │ 6 底停靠（折叠 / 240 px）      │                │
├────────────┴────────────────────────────────┴────────────────┤
│ 7 状态栏（24 px）                                             │
└──────────────────────────────────────────────────────────────┘
```

| # | 区域 | 必需 | 默认尺寸 | 可调 |
|---|---|---|---|---|
| 1 | 菜单栏 | 是 | 32 px | 否 |
| 2 | 功能区 | 是 | 72 px | 可折叠到 0 |
| 3 | 左停靠 | 是 | 280 px | 240–400 px |
| 4 | 视口 | 是 | 弹性 | 最小 480×360 px |
| 5 | 右停靠 | 是 | 340 px | 260–600 px |
| 6 | 底停靠 | 是 | 折叠 | 0 或 160 px–视口 40% |
| 7 | 状态栏 | 是 | 24 px | 否 |

**不变量：** 1440×900、各停靠默认宽度下，视口至少 720×520 px。若计算值更小，先折叠停靠，再考虑压缩视口下限。

### 3.2 菜单栏

| 菜单 | 内容 |
|---|---|
| 文件 | 新建、打开、最近、保存、另存为、导入、导出、关闭 |
| 编辑 | 撤销、重做、剪切/复制/粘贴（预留）、删除、全选 |
| 视图 | 显示样式、楼层视图、剖切、网格、捕捉、面板、重置布局 |
| 建模 | 专业切换、创建、修改、测量 |
| 工具 | 控制台、AI 助手、诊断、设置 |
| 帮助 | 快捷键、文档、示例项目、关于 |

菜单项必须映射到快捷键注册表中的命令 ID；没有对应命令的菜单项属于缺陷。

### 3.3 功能区

功能区是**上下文相关**且**按专业限定**的，只展示当前专业与当前选择类型可用的命令。

| 区段 | 内容 |
|---|---|
| 左 | 专业标签：建筑、土木、工厂、机械 |
| 中 | 当前专业的命令组（创建、修改、基准、测量、交换） |
| 右 | 当前工具指示与取消入口 |

规则：

1. 切换专业只改变命令集，不得修改模型。
2. 不可用命令在提示中说明原因后**禁用**；仅对当前选择类型无效的命令才隐藏。
3. 拾取会话进行中，当前工具必须始终可见。
4. `Esc` 先取消当前工具，再关闭面板。

需求：UI-SHL-07。

### 3.4 左停靠

| 标签页 | 内容 | 默认 |
|---|---|---|
| 对象 | 带可见性与选择的对象树 | 激活 |
| 轴网 | 基准轴网与楼层 | 未激活 |
| 构件库 | 可按系列筛选的可用构件 | 未激活 |

规则：隐藏时仅保留持有临时状态的标签挂载（对象树滚动位置、构件库筛选）；重型 3D 预览必须卸载。

### 3.5 视口

拥有 3D 场景、视图立方、竖向工具条、剖切手柄、测量覆盖层与快捷键提示。默认布局下不得被属性面板覆盖。

### 3.6 右停靠

| 标签页 | 内容 | 自动激活 |
|---|---|---|
| 属性 | 选中对象、目录引用、参数 | 选中时 |
| 创建 | 当前创建表单 | 工具激活时 |
| 构件 | 目录浏览器 | 手动 |
| 领域 | 专业快捷操作 | 手动 |

自动激活不得从视口抢走焦点：标签切换，但键盘焦点仍在视口。

### 3.7 底停靠

| 标签页 | 内容 | 默认 |
|---|---|---|
| 控制台 | Omcom JSON 控制台 | 激活 |
| AI | 助手对话 | 未激活 |
| 输出 | 最近操作与错误 | 未激活 |
| 历史 | 撤销栈浏览器 | 未激活 |

底停靠默认折叠，以保护视口高度。

### 3.8 状态栏

见 §6。

## 4. 停靠模型

### 4.1 停靠解剖

每个停靠包含：头部（标签条 + 溢出菜单 + 折叠按钮）、内容区、可选页脚。停靠与视口是兄弟关系，除浮动模式外不得覆盖视口。

### 4.2 尺寸规则

| 规则 | 取值 |
|---|---|
| 分隔条宽度 | 4 px 命中区，1 px 视觉 |
| 拖动步进 | 1 px，按 2 px 吸附 |
| 双击分隔条 | 恢复默认宽度 |
| 键盘调整 | 聚焦分隔条，`←`/`→` 每次 16 px，`Home` 复位 |
| 持久化 | 按停靠、按层级存储宽度 |
| 需求 | UI-SHL-03, UI-SHL-04, UI-SHL-05 |

### 4.3 标签行为

- 标签先按注册表 `order` 排序，再按用户拖拽顺序。
- 带未保存表单状态的标签显示圆点指示。
- 关闭正在运行操作的标签会被阻止并说明原因。
- `Ctrl/Cmd+W` 关闭当前标签；`Ctrl/Cmd+Shift+W` 关闭停靠（如果可选）。

### 4.4 浮动模式

浮动是**逃生通道**，不是默认形态。

| 规则 | 取值 |
|---|---|
| 触发 | 把标签拖出停靠，或在溢出菜单选择"浮动" |
| 窗口 | 应用内浮层（不是浏览器窗口） |
| 边界 | 必须留在应用视口内，距边至少 32 px |
| 持久化 | 按面板 ID 保存位置与尺寸 |
| 归位 | "停靠"操作恢复到上次停靠位置 |
| 非目标 | 多显示器可拆窗口 |
| 需求 | UI-SHL-09 |

## 5. 布局持久化

| 规则 | 取值 |
|---|---|
| 存储 | `localStorage`，键 `omnim.layout.v1` |
| 结构 | `{ version, level, docks: { left, right, bottom }, ribbonCollapsed, floating: [] }` |
| 写入时机 | 变更后防抖 300 ms；卸载时冲刷 |
| 迁移 | 未知版本 → 丢弃并使用默认值，绝不崩溃 |
| 重置 | 视图 → 面板 → 重置布局，带确认 |
| 损坏数据 | 忽略，记录诊断事件，恢复默认 |
| 需求 | UI-SHL-06 |

**不变量：** 布局状态仅属于界面。不得写入项目文件，因为布局是"每个用户"而不是"每个项目"。

## 6. 状态栏契约

| 槽位 | 内容 | 更新触发 |
|---|---|---|
| 坐标 | 光标世界坐标（米，3 位小数） | 指针移动（50 ms 节流） |
| 选择 | `已选 n` 或单选对象类型 | 选择变化 |
| 单位 | `m` 或 `mm` 上下文指示 | 焦点变化 |
| 保存状态 | `已保存 HH:MM:SS` / `未保存` / `保存中…` / `保存失败` | 项目状态机 |
| 帧率 | 滚动 1 秒 FPS，仅开发者模式显示 | 渲染循环采样 |

规则：状态栏只读；点击槽位可以打开相关面板，但不得修改状态。需求：UI-SHL-08。

## 7. 响应式折叠

| 宽度 | 行为 |
|---|---|
| ≥1600 px | 全部停靠使用存储宽度，底停靠可展开 |
| 1280–1599 px | 右停靠上限 420 px，左停靠上限 320 px |
| 1024–1279 px | 两侧停靠折叠为 44 px 图标条，底停靠自动折叠——**降级，未认证** |
| <1024 px | 不支持；显示阻断提示与最低要求 |

视口下限（480×360）始终优先于停靠宽度。需求：UI-SHL-11, UI-CMP-05。

## 8. 命令面板

| 规则 | 取值 |
|---|---|
| 快捷键 | `Ctrl/Cmd+K` |
| 行为 | 对命令注册表做模糊搜索，按功能区组分组 |
| 行内容 | 命令名、快捷键、禁用原因 |
| 执行 | `Enter` 执行；`Esc` 关闭并恢复焦点 |
| 覆盖 | 每个启用的功能区命令都必须可达 |
| 非目标 | 自由文本命令（那是 Omcom 控制台） |
| 需求 | UI-SHL-12 |

## 9. 非目标

1. 多窗口或可拆面板。
2. 四个位置之外的用户自定义停靠布局。
3. 外壳的自由画布布局。
4. 1024 px 以下的移动或平板布局。
