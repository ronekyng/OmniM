# OmniM 界面可访问性契约

> **契约范围。** 本文固定可访问性目标、WCAG 映射、键盘完备性、焦点管理、语义、替代方案、动效、高对比与实时播报。它是需求 `UI-A11Y-01` … `UI-A11Y-08` 的规范来源。
>
> **双轨维护义务**：`A11Y.zh-CN.md` 是持续维护的译文。在同一次变更中保持章节编号、WCAG 条款与需求 ID 一致。
>
> **状态。** 设计契约。语义、焦点与 axe 审计切片已落地（`web/e2e/a11y.spec.ts`、`web/e2e/focus.spec.ts`、`web/e2e/axe.spec.ts`）；剩余缺口见 [FRONTEND_MATURITY](../../status/FRONTEND_MATURITY.zh-CN.md)。

## 1. 目的与目标

**目标：所有关键路径达到 WCAG 2.2 AA**，并对齐 EN 301 549 以满足采购要求。

关键路径是：首次启动、打开项目、创建对象、选择与属性、保存、错误恢复。只有自动化检查与人工键盘/读屏检查都通过，路径才算合规。

可访问性不是一个独立模式：默认界面就必须能在没有鼠标的情况下使用，高对比主题是额外辅助。

## 2. WCAG 2.2 AA 映射

| WCAG 成功准则 | 适用对象 | 契约实现 |
|---|---|---|
| 1.3.1 信息与关系 | 树、表、停靠 | 语义 role 与标题（§5） |
| 1.4.1 色彩使用 | 选中、状态、错误 | 颜色 + 图标/文字，绝不只靠颜色 |
| 1.4.3 对比度（最低） | 全部文本 | 令牌组合按 4.5:1 审计 |
| 1.4.11 非文本对比 | 边框、焦点环、视口选中 | 相对相邻色 3:1 |
| 1.4.12 文本间距 | 面板 | 布局容忍 1.5 倍行高 |
| 2.1.1 键盘 | 全部命令 | 快捷键注册表覆盖（§3） |
| 2.1.2 无键盘陷阱 | 弹窗 | 陷阱是刻意的且可退出（§4） |
| 2.4.3 焦点顺序 | 工作区 | DOM 顺序与视觉顺序一致 |
| 2.4.7 焦点可见 | 全部控件 | 2 px 环，令牌驱动 |
| 2.4.11 焦点未被遮挡 | 停靠面板 | 聚焦元素不被浮层遮住 |
| 2.5.7 拖拽动作 | 分隔条、剖切手柄 | 提供键盘替代 |
| 3.2.2 输入时 | 表单 | 值变化不触发导航 |
| 3.3.1 错误识别 | 表单、操作 | 错误码 + 文案 + 恢复（§[FEEDBACK_ERRORS](FEEDBACK_ERRORS.zh-CN.md) §5） |
| 4.1.2 名称、角色、值 | 全部组件 | 组件契约（[DESIGN_SYSTEM](DESIGN_SYSTEM.zh-CN.md) §9） |
| 4.1.3 状态消息 | 提示、保存状态 | `aria-live`（§9） |

需求：UI-A11Y-01。

## 3. 键盘完备性

| 规则 | 取值 |
|---|---|
| 覆盖 | 每个命令都能不用指针完成 |
| 可发现 | `F1` 打开快捷键参考；命令面板每行显示快捷键 |
| 遍历 | `Tab` 在区域间移动；`F6` 循环区域（菜单、功能区、左停靠、视口、右停靠、底停靠、状态栏） |
| 树 | 方向键导航；`←`/`→` 折叠/展开；`Enter` 激活；`F2` 重命名 |
| 表 | 方向键移动单元；`Enter` 编辑；`Esc` 取消编辑 |
| 视口 | 全部视图命令可通过功能区与命令面板完成 |
| 需求 | UI-A11Y-02 |

**证明：** 一份纯键盘走查脚本能在无指针情况下完成 J1（创建并保存）。

## 4. 焦点管理

| 事件 | 行为 |
|---|---|
| 区域切换（`F6`） | 焦点移到该区域的第一个可聚焦元素 |
| 面板标签切换 | 焦点留在标签上；内容可用 `Tab` 到达 |
| 弹窗打开 | 焦点到第一个有意义的控件；背景惰性 |
| 弹窗关闭 | 焦点回到触发者 |
| 提示消息 | 绝不抢焦点 |
| 错误边界 | 焦点到兜底标题并播报 |
| 路由变化 | 焦点到页面 `<h1>` |

规则：

1. 焦点始终可见：2 px 环、2 px 偏移、使用 `--focus-ring`。
2. 指针交互使用 `:focus-visible`，鼠标点击不显示焦点环。
3. 移除持有焦点的元素时，焦点移到有记录的相邻元素，绝不落到 `<body>`。

需求：UI-A11Y-03。

## 5. 语义与 ARIA

| 组件 | Role | 必需状态 |
|---|---|---|
| 对象树 | `tree` / `treeitem` | `aria-expanded`、`aria-selected`、`aria-level` |
| 属性表 | `table` 含 `row`/`columnheader`/`cell` | `aria-rowcount`、`aria-colcount` |
| 停靠标签 | `tablist`/`tab`/`tabpanel` | `aria-selected`、`aria-controls` |
| 功能区组 | `toolbar` | `aria-label`、`aria-orientation` |
| 弹窗 | `dialog` + `aria-modal="true"` | `aria-labelledby`、`aria-describedby` |
| 菜单 | `menu`/`menuitem` | `aria-haspopup`、`aria-expanded` |
| 提示区域 | `status`/`alert` | `aria-live` |
| 视口 | `application` 或带描述的 `img` | `aria-label`、`aria-describedby` |

规则：

1. 没有匹配键盘行为的 `role` 不得使用。
2. `aria-label` 文案必须本地化并来自 i18n 词典。
3. 装饰图标使用 `aria-hidden="true"`；有含义的图标必须位于有名称的按钮内。

需求：UI-A11Y-04。

## 6. 名称与替代方案

| 元素 | 可访问名称来源 |
|---|---|
| 图标按钮 | 命令标签的 `aria-label` |
| 数值框 | 可见标签 + 描述中的单位 |
| 视口 | 可见对象数、当前楼层、相机模式的摘要 |
| 仅画布内容 | 属性面板中的文本替代与"描述场景"操作 |
| 状态栏 | 各槽位独立标签，而不是一串拼接文本 |

需求：UI-A11Y-05。

## 7. 动效与对比度偏好

| 偏好 | 行为 |
|---|---|
| `prefers-reduced-motion: reduce` | 移除面板滑动/淡入、视图立方缓动、提示动画；保留 ≤100 ms 的不透明度变化 |
| `prefers-contrast: more` | 首次启动自动应用高对比主题 |
| `forced-colors: active` | 遵循系统颜色；禁用自定义阴影与渐变 |

需求：UI-A11Y-06。

## 8. 高对比主题

| 规则 | 取值 |
|---|---|
| 激活 | 设置中手动开启，或在 `prefers-contrast: more` 下自动 |
| 背景 | `#000000`，文本 `#ffffff` |
| 强调色 | 饱和色，黑底上 ≥4.5:1 |
| 边框 | 至少 1 px，3:1 可见 |
| 焦点 | 2 px `#ffffff`，内侧 1 px 黑环 |
| 阴影 | 禁用 |
| 图标 | 描边至少 1.5 px，不得只用细线 |
| 需求 | UI-A11Y-07 |

## 9. 实时播报

| 事件 | 消息 | 礼貌级别 |
|---|---|---|
| 对象创建 | "{名称} 已创建" | polite |
| 选择变化 | "{类型}，{名称}" 或 "已选 {n} 个对象" | polite |
| 保存完成 | "项目已于 {时间} 保存" | polite |
| 保存失败 | "保存失败：{原因}。修改保留在内存中。" | assertive |
| 错误边界 | "该面板加载失败。{恢复动作}" | assertive |
| 进度里程碑 | "{阶段}，{百分比}" | polite，节流 2 秒 |

规则：每个严重度一个实时区域，绝不与提示消息复用；消息本地化；快速事件合并。

需求：UI-A11Y-08。

## 10. 测试与证据

| 层次 | 工具 | 门禁 |
|---|---|---|
| 自动规则 | Playwright 中的 axe-core 覆盖关键路径 | G2 |
| 键盘 | 人工脚本化走查，录制 | G2 |
| 读屏 | NVDA（Windows）与 VoiceOver（macOS）抽查 | G2 |
| 对比度 | 双主题下的令牌审计脚本 | G2 |
| 合规产物 | 可访问性一致性报告（ACR/VPAT）草稿 | G3 |

**规则：** 阻塞关键路径的可访问性缺陷在每个门禁都是发布阻塞项。

## 11. 非目标

1. WCAG 3.0 合规。
2. 对 3D 空间操作的完整读屏支持。
3. 建模操作的音频替代。
4. AA 之外的认知可访问性认证。
