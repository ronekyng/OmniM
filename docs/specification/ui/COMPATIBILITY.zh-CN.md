# OmniM 界面兼容性矩阵

> **契约范围。** 本文固定支持的浏览器、WebGL 能力门控、显示与输入矩阵、3D 鼠标策略、网络降级与测试流程。它是需求 `UI-CMP-01` … `UI-CMP-06` 的规范来源。
>
> **双轨维护义务**：`COMPATIBILITY.zh-CN.md` 是持续维护的译文。在同一次变更中保持章节编号、矩阵行与需求 ID 一致。
>
> **状态。** 设计契约。目前没有兼容性套件。

## 1. 目的

商业工程软件会明确声明它在哪里运行。"在我浏览器里能用"不是支持策略。

## 2. 浏览器矩阵

| 浏览器 | 版本 | 层级 | 说明 |
|---|---|---|---|
| Chrome / Edge（Chromium） | 最近两个稳定版 | **主要** | 性能参考浏览器 |
| Firefox | 最近两个稳定版 | 支持 | 验证指针锁定与阴影质量 |
| Safari（macOS） | 最近两个大版本 | 支持 | 需要 WebGL2；Windows 无 Safari |
| Safari（iOS/iPadOS） | — | **不支持** | 非目标平台 |
| 其他 Chromium 构建 | 同引擎版本 | 尽力而为 | 不做支持承诺 |

规则：

1. "最近两个"指发布时的当前与上一个主版本。
2. 浏览器退出支持必须提前一个次要版本在发布说明中废弃。
3. 主浏览器每个 PR 跑测试；完整矩阵每个候选版本跑一次。

需求：UI-CMP-01。

## 3. WebGL 能力

| 检查 | 缺失时的动作 |
|---|---|
| WebGL2 上下文 | 阻断，并说明要求与如何开启硬件加速 |
| `EXT_color_buffer_float` | 关闭类 HDR 色调映射回退；继续 |
| 实例化数组 | 关闭实例化路径；在诊断中警告 |
| 最大纹理 < 4096 | 降低阴影贴图；继续 |
| 检测到软件渲染器 | 警告一次，允许进入，记录遥测事件 |

规则：

1. 能力检测在首次场景构建之前完成，并在会话内缓存。
2. 阻断页不得是白屏；需包含所需能力、检测到的 GPU 字符串与诊断导出。
3. 应用绝不静默降级为纯 2D 模式。

需求：UI-CMP-02。

## 4. 显示与输入

### 4.1 DPI 与缩放

| 设置 | 要求 |
|---|---|
| DPI 100% / 125% / 150% / 200% | 控件不裁剪，停靠不重叠 |
| 浏览器缩放 80% / 100% / 125% / 150% / 200% | 布局重排；画布正确缩放 |
| 混合 DPI 多显示器 | 窗口跨屏移动后布局保持 |
| 色彩配置 | 假定 sRGB；模型数据不做色彩管理 |

### 4.2 最小尺寸

| 尺寸 | 行为 |
|---|---|
| ≥1920×1080 | 完整布局 |
| 1440×900 | 完整布局，参考截图尺寸 |
| 1280×720 | **最低认证尺寸**；两侧停靠折叠为图标条 |
| 1024×720 – 1279×720 | 降级：仅图标条，不纳入支持认证 |
| <1024×720 | 阻断提示并给出最低要求 |

需求：UI-CMP-03, UI-CMP-05。

## 5. 3D 鼠标

| 规则 | 取值 |
|---|---|
| 状态 | 本版本**不支持**，并明确声明 |
| 检测 | 若存在 3Dconnexion 设备，关于对话框说明不支持 |
| 未来 | 支持需要专用导航适配器与设备测试矩阵 |
| 需求 | UI-CMP-04 |

声明"不支持"也是兼容契约的一部分：用户不应通过试错才发现。

## 6. 网络降级

| 条件 | 界面 |
|---|---|
| 启动时服务不可达 | 阻断页，说明"启动本地服务"并提供重试 |
| 会话中断线 | 横幅"已断开——修改可能无法保存"；保存禁用；带退避的重试循环 |
| 响应缓慢（>5 s） | 进度指示；禁止重复提交 |
| 响应部分失败 | 操作级错误并可重试；不得出现静默的部分模型 |
| 需求 | UI-CMP-06 |

规则：本版本没有离线编辑队列；宁可如实告知，也不给虚假的"已保存"状态。

## 7. 测试流程

| 层次 | 范围 | 频率 |
|---|---|---|
| 冒烟 | 主浏览器、关键路径 | 每个 PR |
| 矩阵 | 全部支持浏览器、关键路径 | 候选版本 |
| 显示矩阵 | 四档 DPI、三种视口尺寸、两套主题 | 候选版本 |
| 能力 | 强制 WebGL2 失败、软件渲染器 | 候选版本 |
| 证据 | 截图集随发布归档 | 发布 |

## 8. 非目标

1. Internet Explorer 或旧版 Edge。
2. 移动浏览器。
3. Chromium/Firefox 之外的 Linux 发行版专用浏览器。
4. 远程桌面 GPU 加速保证。
