# OmniM 界面数据完整性与项目生命周期

> **契约范围。** 本文固定项目首页、打开/最近、元信息、保存状态机、自动保存、崩溃恢复、冲突处理、快照与最小服务端契约。它是需求 `UI-DAT-01` … `UI-DAT-10` 的规范来源。
>
> **双轨维护义务**：`DATA_INTEGRITY.zh-CN.md` 是持续维护的译文。在同一次变更中保持章节编号、端点名与需求 ID 一致。
>
> **状态。** 设计契约。客户端已调用 `POST /api/project/save`（显式保存、Ctrl/Cmd+S）与 `POST /api/project/save-as`；项目首页路由与 open/new 端点仍未实现。见 [CODE_DEVIATIONS §7](../../status/CODE_DEVIATIONS.zh-CN.md)。

## 1. 目的

建模工作是用户的资产。因此数据完整性是一个有显式状态的产品特性，不是实现细节。本契约保证三件事：

1. 用户始终知道打开了哪个项目、是否已保存。
2. 任何操作都不能静默丢弃工作。
3. 任何中断都有有界、可见的恢复路径。

## 2. 界面中的项目模型

### 2.1 项目首页

| 元素 | 规则 |
|---|---|
| 路由 | `/projects` |
| 内容 | 新建项目、打开文件、最近（最多 10 条）、示例项目 |
| 最近行 | 名称、路径、最后打开时间、大小、缺失依赖标记 |
| 空状态 | 说明当前没有打开项目，并提供示例项目 |
| 行为 | 未新建或打开项目前，工作区不可进入 |
| 需求 | UI-DAT-01 |

**不变量：** 应用绝不从工作目录隐式加载项目。可以作为"上次会话"推荐，但必须由用户确认。

### 2.2 打开与最近

| 规则 | 取值 |
|---|---|
| 打开 | 文件选择器限制在允许根目录内（见 [SECURITY_PRIVACY](SECURITY_PRIVACY.zh-CN.md) §4） |
| 最近记录 | 存在本机用户设置中，不写入项目文件 |
| 文件缺失 | 行保留并显示错误标记与"定位…"操作 |
| 并发打开 | 本版本每会话只打开一个项目 |
| 需求 | UI-DAT-01 |

### 2.3 元信息

首次保存前可编辑，之后通过项目设置修改。

| 字段 | 类型 | 默认 | 持久化 |
|---|---|---|---|
| 名称 | 字符串，根目录内唯一 | "未命名" | 是 |
| 描述 | 字符串 | 空 | 是 |
| 单位制 | `metric` \| `imperial`（仅显示单位；存储几何保持米制） | `metric` | 是 |
| 模式版本 | 整数 | 当前版本 | 是（只读） |
| 作者 / 组织 | 字符串 | 空 | 是 |
| 创建 / 修改时间 | 时间戳 | 当前 | 是（只读） |

需求：UI-DAT-07。

### 2.4 依赖报告

打开时，客户端把所需的目录与系列引用与服务端可解析的内容做比对。

| 条件 | 界面 |
|---|---|
| 全部可解析 | 静默 |
| 缺失系列 | 横幅："缺失 3 个系列——构件可能回退为网格"，附列表 |
| 缺失目录定义 | 横幅："2 个构件定义未解析"，附受影响对象数 |
| 外部文件缺失 | 横幅，提供"定位…"与"以只读继续" |
| 需求 | UI-DAT-09 |

**规则：** 报告在编辑前是信息性的；只有需要该缺失定义的操作才会被阻断。

## 3. 保存状态机

### 3.1 状态

```text
clean ──变更──▶ dirty ──保存──▶ saving ──成功──▶ clean
  ▲                ▲                 │
  │                └──────失败───────┘
  └──────────────── 另存为 ───────────┘
```

| 状态 | 状态栏 | 标题 | 允许操作 |
|---|---|---|---|
| `clean` | `已保存 HH:MM:SS` | 项目名 | 全部 |
| `dirty` | `未保存` | `• 项目名` | 全部；关闭时提示 |
| `saving` | `保存中…` | 项目名 | 只读操作 |
| `failed` | `保存失败` | `• 项目名` | 重试、另存为、导出 |
| `readonly` | `只读——外部变更` | `🔒 项目名` | 仅查看 |
| 需求 | UI-DAT-02, UI-DAT-03 |

### 3.2 脏跟踪与最后保存时间

- 变更把会话标记为脏；保存成功后记录 `last_saved_at` 并清除。
- 视图变化、选择、面板布局、主题**不**标记为脏。
- 自动保存不清除脏状态（脏的含义是"尚未写入用户的目标文件"）。
- 时间按本地时间显示到秒。
- 需求：UI-DAT-03。

### 3.3 未保存变更拦截

触发场景：关闭标签、打开另一个项目、新建项目、刷新、离开页面。

| 选择 | 行为 |
|---|---|
| 保存 | 保存后继续；失败则停留并报错 |
| 放弃 | 继续；不写入即关闭项目 |
| 取消 | 中止导航，保留会话 |

规则：

1. 弹窗必须写出项目名与最后保存时间。
2. `beforeunload` 仅在 `dirty` 时使用，且不得阻断应用内显式导航。
3. 键盘：`Esc` = 取消，`Enter` = 保存（安全默认）。
4. 需求：UI-DAT-06。

### 3.4 保存失败

| 原因 | 界面 |
|---|---|
| 服务不可达 | 错误弹窗 + 重试 + 另存为；状态保持 `dirty` |
| 权限不足 | 显示路径与恢复方式的错误；提供另存为 |
| 磁盘已满 | 带大小提示的错误；提供另存到其他位置 |
| 序列化错误 | 错误码 + 诊断导出；绝不部分写入 |

**不变量：** 保存失败绝不清除脏状态，也绝不报告成功。

## 4. 自动保存

| 规则 | 取值 |
|---|---|
| 间隔 | 变更后 60 秒无操作，或连续编辑 5 分钟 |
| 目标 | 项目文件之外的恢复文件（例如 `~/.omnim/recovery/<project-hash>/`） |
| 阻塞 | 不得阻塞输入；与显式保存使用同样的原子写 |
| 失败 | 记录日志，每会话最多弹出一次警告横幅，绝不静默忽略 |
| 保留 | 保留最近 5 个快照，更早的清理 |
| 需求 | UI-DAT-04 |

自动保存绝不写入用户的项目路径。该路径只由显式保存、另存为或服务端配置的自动保存策略写入——两者不得同时生效。

## 5. 崩溃恢复

| 步骤 | 行为 |
|---|---|
| 检测 | 打开项目时，查找比项目 mtime 更新的恢复快照 |
| 提示 | "恢复 HH:MM 的未保存工作（N 分钟前）？"提供对比、恢复、丢弃 |
| 恢复 | 把快照载入会话，标记为脏，原文件保持不变 |
| 丢弃 | 确认后删除快照 |
| 保证 | 会话运行 ≥1 分钟时，最多损失 5 分钟工作 |
| 需求 | UI-DAT-05 |

**验证：** 编辑中途杀掉服务与浏览器，重启后确认恢复提示与对象数量。

## 6. 外部变更与冲突

| 信号 | 检测 | 界面 |
|---|---|---|
| mtime 变化 | 聚焦时与保存前比对 stat | 只读横幅，提供重新加载 / 另存为 |
| 内容哈希变化 | 打开时与保存前计算哈希 | 同上，警告更强 |
| 文件被删除 | stat 不存在 | 只读横幅，提供"另存为" |
| 需求 | UI-DAT-08 |

规则：

1. 绝不自动覆盖被外部修改的文件。
2. 重新加载会丢弃会话未保存修改，必须先显式确认。
3. 若双方都已修改，提供另存为而不是合并（本版本无合并界面）。

## 7. 破坏性操作快照

| 操作 | 快照 | 恢复点 |
|---|---|---|
| 删除对象 | 是，经撤销隐式 | 撤销 |
| 替换式导入 | 是，命名快照 | 项目设置 → 快照 |
| 批量属性更新 | 是，对象 > 20 时 | 快照 |
| 特征重建失败 | 是，重建前 | 快照 |

规则：

1. 快照存储在项目旁（`.omnim.snapshots/`）。
2. 每个快照记录标签、时间、对象数与创建它的命令 ID。
3. 恢复快照本身在会话内可撤销，并且总是先提供"另存为"。
4. 需求：UI-DAT-10。

## 8. 服务端契约（最小集）

这些端点是界面**必需**的。除 `GET /api/project` 与 `POST /api/project/save` 外，目前都不存在。

| 方法 | 路径 | 用途 | 说明 |
|---|---|---|---|
| GET | `/api/project` | 项目状态 | 增加 `path`、`dirty`、`last_saved_at`、`schema_version` |
| POST | `/api/project/new` | 创建并切换 | Body：名称、根目录、可选模板 |
| POST | `/api/project/open` | 按路径打开 | 路径限制在允许根目录 |
| POST | `/api/project/save` | 显式保存 | 已存在；返回路径与时间 |
| POST | `/api/project/save-as` | 另存到新路径 | 返回新路径；更新会话 |
| GET | `/api/project/recent` | 最近列表 | 服务端列表并检查存在性 |
| GET | `/api/project/autosaves` | 恢复快照 | 仅当前项目 |
| POST | `/api/project/restore` | 恢复快照 | Body：快照 ID |

规则：

1. `save_path` 变为可变会话状态；切换项目不得泄漏撤销历史。
2. 每个端点返回带 `OMNI-*` 错误码的类型化错误。
3. 新建/打开在网络失败重试时必须幂等。
4. 项目切换时重置撤销/重做状态。

## 9. 非目标

1. 多文档界面（同时打开多个项目）。
2. 云同步或冲突合并。
3. 版本控制集成。
4. 恢复文件的后台自动上传。
