# OmniM 界面交互契约

> **契约范围。** 本文固定命令模型、选择、拾取、快捷键注册表、上下文菜单、对话框、撤销、命名、单位与视口导航。它是需求 `UI-INT-01` … `UI-INT-12` 的规范来源。
>
> **双轨维护义务**：`INTERACTION.zh-CN.md` 是持续维护的译文。在同一次变更中保持章节编号、表格、快捷键与需求 ID 一致。
>
> **状态。** 设计契约。拾取状态机已存在于 `web/src/shared/creation/stateMachine.ts`；其余为目标行为。

## 1. 目的

交互是工程工具建立信任的地方。本契约让行为在不同专业与输入设备间保持一致，并把键盘覆盖度作为一等属性，而不是补丁。

## 2. 命令模型

每个用户动作都是一个**命令**，包含 ID、标签键、图标、可选快捷键、可用性判定与执行处理器。

| 字段 | 规则 |
|---|---|
| `id` | 稳定、点分：`wall.create`、`view.fit`、`file.save` |
| `labelKey` | i18n 键；不得使用字面文本 |
| `group` | 功能区组；决定命令面板排序 |
| `shortcut` | 只能来自快捷键注册表 |
| `enabled(ctx)` | 应用状态的纯函数；为 false 时必须给出原因 |
| `run(ctx)` | 可以开启拾取会话；不得产生隐藏副作用 |

**规则：** 菜单、功能区按钮、命令面板、上下文菜单都从该注册表渲染。只出现在一个入口的命令属于缺陷。

## 3. 选择模型

| 手势 | 结果 | 需求 |
|---|---|---|
| 左键单击对象 | 用该对象替换选择 | UI-INT-01 |
| Ctrl/Cmd + 单击 | 在选中集合中切换该对象 | UI-INT-01 |
| 左键单击空白 | 清空选择 | UI-INT-01 |
| 在空白处拖拽 | 框选；Ctrl/Cmd 追加选择 | UI-INT-01 |
| `Esc` | 清空选择（若工具有效则先取消工具） | UI-INT-01 |
| `Ctrl/Cmd+A` | 选择全部可见对象 | UI-INT-01 |
| `Shift` + 树中单击 | 在对象树中范围选择 | UI-INT-01 |

规则：

1. 选择是有序对象 ID 集合，按拾取时间排序。
2. 混合类型多选时，属性面板显示多对象摘要。
3. 隐藏对象不能被视口拾取，但仍可从树中选择。
4. 选择变化需向辅助技术播报（见 [A11Y](A11Y.zh-CN.md) §9）。

## 4. 拾取会话状态机

### 4.1 状态

| 状态 | 含义 | 视口光标 | 底部提示 |
|---|---|---|---|
| `idle` | 没有创建进行中 | 默认 | 快捷键提示 |
| `configuring` | 表单打开，等待参数 | 默认 | "配置参数后开始拾取" |
| `picking` | 正在收集点 | 十字 | "回车完成 · 退格撤点 · Esc 取消" |
| `creating` | 请求进行中 | 等待 | "创建中…" |
| `done` | 成功，瞬时 | 默认 | 对象名称 |
| `error` | 失败，保留表单 | 默认 | 错误码 + 恢复动作 |

### 4.2 转换

```text
idle ──激活工具──▶ configuring ──开始──▶ picking
                                          │  ▲
                              加点        │  │ 退格
                                          ▼  │
                                       picking
                                          │ 回车 / 自动闭合
                                          ▼
                                      creating
                                       │      │
                                  成功 │      │ 失败
                                       ▼      ▼
                                     done   error
                                       │      │
                                       └──────┴──▶ idle（取消 / 重试）
```

规则：

1. 视工具类型，`configuring` 与 `picking` 可以互换顺序，但 `creating` 始终是会话的终态。
2. `error` 绝不丢弃表单；用户修正参数后可重试。
3. `picking` 中按 `Esc` 结束会话；`error` 中按 `Esc` 回到 `configuring`。
4. 撤点只允许撤销最后一个点（退格），不支持任意删除。
5. 自动闭合：多边形工具点击首点闭合；线性工具需要回车。

需求：UI-INT-02。验证：`web/src/__tests__/stateMachine.test.ts`。

### 4.3 拾取中的键盘

| 键 | 动作 |
|---|---|
| `Enter` | 达到最少点数后完成 |
| `Backspace` | 移除最后一个点 |
| `Esc` | 取消会话 |
| `Shift`（按住） | 相对上一点正交约束 |
| 方向键 | 按捕捉步长微移待定点（预留） |

### 4.4 预览规则

预览必须使用与最终对象相同的几何内核参数（见创建管线契约）。预览颜色来自视口调色板；幽灵预览不透明度不得超过 35%。

## 5. 快捷键注册表

### 5.1 注册表结构

```ts
type Shortcut = {
  id: string;            // 命令 id
  keys: string;          // "ctrl+s", "shift+f10"
  scope: "global" | "viewport" | "tree" | "dialog";
  when?: (ctx: ShortcutContext) => boolean;
  allowInInput?: boolean; // 默认 false
};
```

一个模块导出完整数组；其他任何地方不得注册全局监听。

### 5.2 文档生成

[KEYBOARD_MAP](../../reference/KEYBOARD_MAP.zh-CN.md) 镜像命令注册表。注册表落地前，`scripts/gen_keymap.py --check` 校验表内一致性与中英对齐；注册表就绪后改为从注册表生成。

**已交付（2026-11-04，G2 · INT-03）**：单一注册表落地——`web/src/app/commands.ts` 的 `buildWorkspaceCommands` 是命令数组唯一产地；`CommandPalette`/`ShortcutHelp` 原样消费；类型 `PaletteCommand` 定义于注册表模块。全局 `window` 键盘监听收敛至 allow-list（`check_ui_contracts global_keydown` 门禁：工作区 dispatch（App.tsx，读注册表）+ 对话框焦点陷阱 useDialogFocus）；组件编辑器的页面键改为**宿主容器监听**（曼面度证件：非 window）。`scripts/gen_keymap.py --check` 继续锁定中英 KEYBOARD_MAP 对齐。

需求：UI-INT-03。

### 5.3 焦点规则

| 上下文 | 全局快捷键 |
|---|---|
| `<input>`、`<textarea>`、`[contenteditable]` | 禁用，除非 `allowInInput` |
| 打开的弹窗 | 仅弹窗作用域快捷键 |
| 属性网格文本编辑 | 除 `Esc`、`Enter` 外禁用 |
| 视口获得焦点 | 全部全局快捷键 |

`Esc` 是唯一例外：它总是解决最内层可取消动作（弹窗 → 拾取 → 选择）。

需求：UI-INT-04。

## 6. 上下文菜单

| 上下文 | 条目 |
|---|---|
| 视口空白 | 粘贴、全选、适配视图、回到首页、切换网格、剖切 |
| 视口已选对象 | 隔离、隐藏、删除、属性、从此处测量 |
| 对象树对象 | 重命名、复制、删除、隐藏/显示、缩放到 |
| 属性行 | 复制值、恢复默认、查看定义 |
| 控制台输出 | 复制、清空 |

规则：

1. 菜单在指针处打开，并限制在视口内。
2. 键盘唤起时在焦点元素的边界处打开。
3. 破坏性条目放在最后、单独分组，多对象时要求确认。
4. 菜单项反映命令可用性并显示快捷键。

需求：UI-INT-05。

**已交付（2026-11-04，G2 · INT-05）**：上下文菜单（对象树行）Shift+F10 键盘唤起；`menu/menuitem` 语义、方向键/焦点环与 Esc 关闭；右键与键盘走同一入口。证据：`web/e2e/a11y.spec.ts`（context menu is keyboard-invokable）。

## 7. 对话框与直接操作

### 7.1 对话框族

| 类型 | 用途 | 按钮 |
|---|---|---|
| 确认 | 破坏性或不可逆操作 | 取消（默认焦点）、确认（危险） |
| 输入 | 单值输入 | 取消、确定 |
| 表单 | 多字段设置 | 取消、应用、确定 |
| 进度 | 长时间操作 | 安全时提供取消 |
| 错误 | 阻断性失败 | 复制详情、重试、关闭 |

### 7.2 焦点管理

1. 打开弹窗时焦点移到第一个有意义的控件（不是关闭按钮）。
2. `Tab`/`Shift+Tab` 在弹窗内循环。
3. `Esc` 关闭，除非破坏性操作正在进行。
4. 关闭后焦点回到触发元素。
5. 背景内容设置为 `aria-hidden` 且惰性。

需求：UI-INT-06。

### 7.3 破坏性确认

对话框必须说明：将删除什么、影响多少对象与子对象、是否可撤销、若不可撤销的恢复路径。

| 动作 | 可撤销 | 确认 |
|---|---|---|
| 删除对象 | 是，经撤销 | 有子对象时必需 |
| 连同子对象删除 | 是，经撤销 | 必需，按类型列出子对象数量 |
| 通过导入替换项目 | 否 | 必需，提供快照 |
| 丢弃未保存变更 | 否 | 必需，三选一 |

需求：UI-INT-07。

### 7.4 双击语义

| 上下文 | 含义 |
|---|---|
| 对象树行 | 就地重命名 |
| 视口对象 | 选中并打开属性（绝不静默修改几何） |
| 视口空白 | 无动作 |
| 停靠分隔条 | 复位宽度 |
| 标签页 | 无动作（避免误关） |
| 属性值 | 进入编辑态 |

**已交付（2026-11-04，G2 · INT-11）**：对象树行双击=就地重命名（`beginRename`，拦截冒泡保证唯一）；停靠分隔条双击=复位宽度（`AppLayout` 已接线）。其余行的行为与上表一致（视口对象双击补齐为"选中并打开属性"路径，空白双击无动作；标签双击无动作）。证据：`web/e2e/a11y.spec.ts`（F2/双击重命名）+ ` gestures.spec` 语义。

需求：UI-INT-11。

## 8. 撤销与重做

| 规则 | 取值 |
|---|---|
| 覆盖 | 每个变更端点必须产生撤销条目 |
| 深度 | 每会话至少 50 步 |
| 显示 | `编辑` 菜单显示下一步撤销/重做的标签 |
| 不可撤销 | 保存、视图变化、选择、面板布局 |
| 历史面板 | 底停靠标签列出条目的标签、时间、对象数；点击恢复该状态 |
| 失败 | 撤销失败不改变状态并报告错误 |
| 需求 | UI-INT-08 |

**不变量：** 若操作不可撤销，界面必须在执行前说明，而不是事后。

## 9. 命名与单位

### 9.1 自动命名

| 规则 | 取值 |
|---|---|
| 模式 | `<类型>-<nnn>`，三位数字，按类型、按项目 |
| 起始 | `001`；删除后只复用最小空号 |
| 唯一性 | 名称在项目内唯一；重复被拒并说明原因 |
| 重命名 | 就地，失焦或回车时校验，可撤销 |
| 本地化 | 类型前缀是否使用本地化名？**否**——前缀固定 ASCII 以便交换 |
| 需求 | UI-INT-09 |

### 9.2 单位显示

| 上下文 | 单位 | 精度 |
|---|---|---|
| 视口坐标 | m | 3 位小数 |
| GenRule 输入 | m | 3 位小数 |
| 目录参数 | mm | 默认 0 位，定义允许小数时例外 |
| 图层编辑器 | mm | 0 位 |
| 角度 | ° | 1 位 |
| 面积 | m² | 2 位 |

规则：每个数值输入都以单位后缀显示；切换单位制只转换显示值，不得静默改写已存几何。需求：UI-INT-10。

**已交付（2026-11-04，G2 · INT-10）**：创建面板所有数值输入带 `.field-unit` 后缀——世界域长度一律 `m`、断面厚一律 `mm`、标高/离地高 `m`；目录参数回显 `{value} {unit}`（mm）；图层面板既有 `mm`。单位制切换仅转换显示（DAT-07 `unit_system` 为显示项）。证据：`web/e2e/units.spec.ts`。

## 10. 视口导航

| 输入 | 轨道 | 平移 | 缩放 |
|---|---|---|---|
| 左键拖拽（无工具） | 选择或框选 | — | — |
| 中键拖拽 | 轨道 | — | — |
| Shift + 中键拖拽 | — | 平移 | — |
| 滚轮 | — | — | 朝光标缩放 |
| 右键拖拽 | 轨道（可配置） | 平移（可配置） | — |
| 视图立方面 | 对齐正交视图 | — | — |

规则：

1. 导航绑定可在设置中配置，并按用户持久化。**当前代码不同：** 左键拖拽平移、中键拖拽推拉、右键拖拽轨道旋转（`ThreeViewer.tsx` 指针处理）。上表是目标行为，差异记录在 [CODE_DEVIATIONS §7](../../status/CODE_DEVIATIONS.zh-CN.md)。
2. `F` 适配全部可见对象；`H` 恢复首页视图。
3. 导航不得清空选择。
4. 需求：UI-INT-12。

**已交付（2026-11-04，G2 · INT-12）**：导航绑定成为**真实设置**——注册表命令 `view.nav` 在命令面板可发现，切换 `current`/`contract` 两制并持久化 `omnim.nav`（Private 模式降内存内），`applyNavScheme` 在工作域挂载与设置变更时施加到 OrbitControls（contract：左键置空=纯选择、中键=轨道、右键=平移、滚轮=朝光标缩放）。仍未完成：Shift+中键平移组合（OrbitControls 无法一键映射修饰键）与"契约制成为默认"——已登记 CODE_DEVIATIONS §7 保持诚实。证据：`e2e/navScheme.spec.ts`。
